# 🖐️ Neon Hand Tracker

Real-time hand tracking with neon glowing effects using MediaPipe and JavaScript.
No installation required — runs directly in the browser!

## ✨ Features

- Real-time hand detection via webcam
- Neon glowing lines between all fingertips
- Cross-hand connections when both hands are visible
- Palm outline with golden glow
- Works with 1 or 2 hands simultaneously

👉 https://im-alisher.github.io/neon-hand-tracker/

## 🛠️ Tech Stack

- MediaPipe Hands
- HTML5 Canvas
- Vanilla JavaScript
- No frameworks, no installation!

## 📦 How to Run Locally

Just open `index.html` in Chrome — that's it!

```bash
git clone https://github.com/monmoymondol/HTML-codes-projects/new/main/neon-hand-tracker.git

cd neon-hand-tracker
# Open index.html in Chrome
```

## 🎮 How to Use

1. Allow camera access
2. Show your hand in front of webcam
3. Watch the neon magic! ✨
4. Show both hands for cross-hand effects
